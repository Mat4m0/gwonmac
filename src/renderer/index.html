Updates

            
Keep the app current without interrupting an active game connection.

          

          

            Version —
            · Unversioned
          

          
          
Beta also receives beta and release-candidate builds, never alpha builds. Switching back to Stable stops future Beta discovery; if the latest Stable is older, GWonMac opens the Releases page for a manual install instead of downgrading itself.

          
          
Checks run when due after launch, at most once every six hours even across restarts, but never during an active game connection. A launch-check update installs before play unless you skip it; one downloaded later installs when you restart. Turn this off to check manually.

          

            
            
            
          

          

          

        

        

          

            
Advanced

            
Diagnostics, memory, and recovery options for troubleshooting the app.

          

          
          
Support may ask you to select a profile to isolate the client, GWonMac transforms, and frame presentation. Nonstandard profiles disable some features. Restart after changing it.

          

          

            

              
              
                Using 2 GB
              
            

            

              Gives Guild Wars more memory for long sessions and may delay memory-related crashes. It does not stop memory that keeps growing. Restart GWonMac after changing this option.
            

            

          

          

            
            

              After Guild Wars reloads, sign in and return to the selected character automatically when the client supports it. This applies to Command-Q, memory warnings, and Reload Game.
            

          

          

          
          
Shows live rendering and memory measurements over the game. Leave it off unless you are investigating performance.

          

          
          
Restores display, tools, and window position. Downloaded game data and your login are kept.

        

        

          

            
Multiple Accounts

            
Open several independent Guild Wars accounts, each in its own window.

          

          
Checking account mode…

          
Your current window, saved login, settings, templates, and builds stay in Single Account mode. Multiple Accounts creates a separate workspace and asks you to sign in once for each account.

          

            

            
Login, game settings, screenshots, chat logs, and Single Account data are never shared. Returning to Single Account restarts GWonMac and preserves both workspaces.

            

              
            

          

          

            

            
GWonMac restarts into the Account Picker. Create and manage every account there, including any one-time copy into your first account.
