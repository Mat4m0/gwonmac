Templates

          

            Checking your saved templates…
          


          

            
            
            
            
          

          

            Export writes every saved build into a folder of .txt files. Import reads that
            folder back, or the Templates folder from a Windows Guild Wars install, or a text
            file holding several codes. Imports arrive in the top level of Skills and
            Equipment, because Guild Wars does not list templates kept in a subfolder here;
            a build from a Windows subfolder keeps that folder in its name.
          


          
          

            

            

            

              
            

            

              Moving keeps the folder name as part of the template name. Once they are
              listed in game you can rename or delete them there.

Display

          

            Graphics quality
            

              
              
              
            

          

          
Retina is the visual-quality default. 1.5× renders 2.25 times the pixels of 1×; 2× renders four times the pixels. Lower values improve performance and reduce GPU memory use.

        


        

          
Controls

          
          
Reads the cursor from your own installed Guild Wars client while you play, instead of the macOS pointer. Nothing is downloaded and no artwork ships with this app. On by default. Changing this restarts the app; you will be asked first.

          

          

          

        


        

          
Updates

          

            Version —
            · Preview
          

          
          
On by default: one check at launch, then a quiet check about every six hours while the app stays open — never while a game connection is open. Turn this off and the app contacts GitHub only when you ask it to — including when it meets a game client build it does not recognise. Downloaded updates are installed when you restart.
