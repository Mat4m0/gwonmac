GWonMac started as a way to play Guild Wars on a Mac without Windows, Wine, or a virtual machine. The next question arrived almost immediately:

> Will GWToolbox++ work?

The answer is still no. GWonMac does not load Windows DLLs and is not building a plugin platform. But the quality-of-life feature people requested most was clear: a practical way to manage complete player and hero builds.

Release `2026.8.5` introduces the first Beta version of **GWonMac Tools**, alongside an experimental 4 GB memory limit, better template migration, and a new Obsidian interface.

## A local home for builds and teams

GWonMac Tools adds a build library designed around the way people actually prepare a Guild Wars party.

You can:

- Save and edit player and hero builds
- Capture your current party as a reusable team
- Keep related variants without duplicating everything by hand
- Edit professions, attributes, skill bars, and hero behavior
- Reorder heroes and skills with drag and drop
- Search skills and group the catalogue by attribute
- Filter for skills that learned by the current character
- Delete builds and teams with confirmation and Undo

## Apply a saved team

From a supported PvE outpost, **Apply team** can configure:

- Normal or Hard Mode
- The player's build
- Hero roster and order
- Primary and secondary professions
- Skill bars and attributes
- Hero behavior

Apply is intentionally observation-driven. It sends one bounded change, waits for Guild Wars to publish and stabilize the result, and only then continues. The interface shows its current phase, reports exactly how many changes were confirmed, and lets you cancel before another command is sent.

This makes applying a team slower than blindly sending every command at once, but much safer and more truthful when Guild Wars is still updating the party.

Team Management is a **Beta** feature. Hard Mode support is included, but additional live tester coverage is welcome.

## What Beta means

GWonMac Tools is optional and off by default. Enable it under:

**Settings → Controls → GWonMac Tools Beta**

The first enable requires restarting Guild Wars because the app must select a certified client module before the game starts. After that restart, individual tool settings can be changed live.

Optional Tools UI, observation, and commands are unavailable in PvP, guild halls, and unknown regions. Core cursor and template behavior remains available independently.

If ArenaNet updates the Guild Wars client before a new build has been certified, GWonMac keeps gameplay available and temporarily disables the affected optional features. It never blocks the game while waiting for a compatibility update.

## Templates work without Tools

Build-template migration is a Core feature and does not require enabling GWonMac Tools.

Under **Settings → Templates**, you can:

- Import an old Windows Guild Wars template folder
- Import templates from files
- Import one or many template codes from the clipboard
- Export your templates
- Recover templates stored in unexpected subfolders

Tools can publish an authored build into Guild Wars, but the Tools library and the game's Templates folder remain separate on purpose. There is one clear owner for each kind of data instead of two libraries silently trying to synchronize.

Read the [template migration guide](/docs/guides/templates) for the complete workflow.

## More memory headroom for long sessions

ArenaNet's official WebAssembly client normally has a 2 GB memory ceiling. Long sessions can eventually approach that limit, especially when memory continues growing as more game data is used.

Compatible Guild Wars builds can now opt into an experimental 4 GB limit under:

**Settings → Advanced → Experimental 4 GB memory limit**

The option is off by default and requires restarting Guild Wars. Settings always reports what the current session is actually using.

The larger limit provides more headroom and may delay a memory-related crash. It does **not** fix memory that continues growing. If the current Guild Wars update has not passed exact-build certification—or preparing the larger client fails—GWonMac starts the standard 2 GB client instead. Gameplay remains available.

The memory warning also received a simpler, non-blocking design. It estimates remaining time from the session's measured growth rate, uses the actual 2 GB or 4 GB cap, and offers a direct way to reload Guild Wars with fresh memory.

## A quieter interface

Release `2026.8.5` also adds redid the whole ingame interface you choose now between **Guild Wars (default)** I tried to get as close to the orginal interface as possible & **Obsidian**, a borderless charcoal interface with restrained gold accents.

Choose it under:

**Settings → Display → Interface style**

The original Guild Wars-inspired interface remains the default. Both styles use the same controls, accessibility behavior, responsive layouts, and profession colors. Panel visibility remains adjustable independently.

## Help test the release

The most useful feedback now is:

- Repeated Team Apply runs with different hero professions and bars
- Diffilcutly application Hard / Normal Mode application
- Larger and unusual hero rosters
- Long sessions using the experimental 4 GB limit
- Interface style and layout feedback

If something fails, please describe what you expected and what Guild Wars showed afterward.
