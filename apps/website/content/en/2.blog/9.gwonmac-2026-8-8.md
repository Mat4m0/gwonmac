Multiple Accounts arrives, Build Management is fully back, and Quick Travel and the Xunlai Chest open with a shortcut. All new gameplay features are opt-in and unavailable in PvP.

- **Multiple Accounts:** run several Guild Wars sessions at the same time, each with its own sign-in.
- **Hero and Build Management (`⌘B`):** fully restored.
- **Quick Travel:** type `/tp` or press `⌘T` to travel to a location.
- **Xunlai Chest:** type `/chest` or press `⌘⇧C` in an outpost to open your storage.
- **Settings:** you can change every Tools shortcut if the defaults do not suit you.
- **Font:** every GWonMac interface now uses the original Guild Wars typeface.
- **Audio:** game sound keeps playing while you use GWonMac controls.
- **Keyboard:** the sign-in screen and in-game overlays now take keyboard input reliably.

## Notes

- If you do not enable Tools, its feature code does not run at all, and nothing changes for you.
- Like Toolbox, Tools is unavailable in PvP areas.
- Larger Toolbox features are not planned. If you cannot play without one, Windows or a Windows virtual machine is probably the better option.
