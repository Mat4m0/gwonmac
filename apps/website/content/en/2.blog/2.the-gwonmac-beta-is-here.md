The first **GWonMac beta** is out! 🎉

You can download `2026.7.0-beta.1` from the [releases page](https://github.com/Mat4m0/gwonmac/releases/latest).

## What's improved

This release fixes several issues reported by alpha testers:

- Fixed overly aggressive auto-run
- Improved camera movement
- Salvage and identification kits are now usable
- Templates can now be saved, loaded, and renamed

It also adds native cursor support: the cursor now changes contextually when performing actions such as salvaging or using the travel map.

## GWonMac Tools

I've started working on **GWonMac Tools**, a collection of optional quality-of-life features built specifically for GWonMac. It's a separate project from GWToolbox++ and will be maintained as part of GWonMac.

If you use GWToolbox++: which three features would you most like to see first? Tell us on [Discord](https://discord.gg/Z9ft52RBD3).

## Known issues

- Adrenaline may flicker; this issue also occurs in the mobile client
- Camera rotation during movement feels clunky on smaller screen sizes

Thank you to everyone who tested the alpha and submitted bug reports — your feedback has been incredibly helpful. If you run into problems with the beta, please [report them](https://github.com/Mat4m0/gwonmac/issues/new?template=bug-report.yml). Every report makes GWonMac better.
