Adds Kamadan trade chat, Fast Reload, and smarter Quick Travel, plus skill key labels and cooldown timers. Tools features are now built to survive small Guild Wars updates.

- **Kamadan Trade Chat (`⌘K`):** browse trade messages and check merchant and trader prices in the game.
- **Fast Reload (`⌘Q`):** restarts only your current Guild Wars session in a few seconds. Select **Return to my character automatically** to log back in to the same character. Use it when memory or texture problems appear.
- **Quick Travel (`⌘T`):** shows only destinations your account can reach, keeps recent destinations per character, and supports `Tab` to move between results.
- **Settings → Display:** choose between two interface styles, or create and apply your own theme.
- **Settings → Display → Controller button symbols:** PlayStation symbols, from the next game start.
- **Settings → Tools → Skill key labels:** custom shortcuts such as `Shift+C` show over the correct skill slot.
- **Settings → Tools → Skill cooldown timers:** remaining recharge time shows over your skills.
- **Input:** many keyboard shortcuts (`⌘K`, `⌘C`, `⌘V`) and mouse actions behave more consistently, and movement keys no longer stick.
- **Windows:** the game window keeps its place when you connect or remove a display.
- **Diagnostics:** clearer reports for Tools, reload failures, and graphics or texture problems.

## Known issues

- The Guild Wars memory limit is not fixed. Fast Reload is the quickest way to recover; the Reload action in the memory warning uses it too.
