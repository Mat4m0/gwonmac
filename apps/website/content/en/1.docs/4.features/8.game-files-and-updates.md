These pages live in the launcher's Settings. They are not in the game window's Hub, which shows them with an arrow and opens the launcher.

## Game files

Game files holds the Guild Wars client that GWonMac runs. Every account shares one copy, and the launcher keeps it up to date. The **Guild Wars client** row shows **Ready**, **Preparing**, or **Needs repair**.

You can press **Play** as soon as the client is ready. The rest of the game data downloads in the background and does not block Play. The **Complete game download** card shows progress. Use **Pause** to stop the download, and **Resume** to continue. If it fails, the card says why and offers **Try again**. When it is done, it reads "All game files are available offline."

If a file is missing or damaged, GWonMac says **Repair needed**. Choose **Repair game files**. You can also run the check yourself with **Check and repair game files**. The launcher restarts to verify the client, so close your game windows first.

**Reset and redownload game files** is under **Advanced** on this page. It removes the downloaded Guild Wars client data and downloads it again after a restart. Your accounts, saved logins, settings, Tools and shortcuts, builds, templates, screenshots, chat logs, and window positions are kept. Use it only when a repair does not help.

- **Turn on:** always on. Nothing to enable.
- **Open:** Settings → :setting[Game files]{to="game-files"} in the launcher. The bottom bar also shows "Preparing Guild Wars" with a percentage while the client is being prepared. When a repair is needed, the main button reads **Open Game Files**.
- **Settings:** **Pause** and **Resume** for the background download, **Check and repair game files**, and **Reset and redownload game files**.
- **Limits:** launcher only. Repair restarts the launcher.

## Updates

Updates covers the GWonMac launcher itself. Guild Wars game files update separately, under Game files.

By default the launcher checks for updates on its own. When one is found, it downloads in the background and you can keep using the launcher. When it is ready, the page reads "Launcher version … is ready". Choose **Restart and update** when you are done playing.

Pick a channel. **Stable** is recommended. **Beta** gets new versions earlier and shows Beta release notes on Home. If you move from Beta back to Stable, the page may say **Stable needs a manual install**. Choose **Open Releases** and download the Stable version. Your accounts and game files stay in place.

- **Turn on:** :setting[Automatically check for launcher updates]{to="updates/autoCheckUpdates"}. It is on by default.
- **Open:** Settings → :setting[Updates]{to="updates"}, or **Check for Updates…** in the app menu.
- **Settings:** :setting[Launcher update channel]{to="updates/updateTrack"} (**Stable** or **Beta**), and **Check now**, which checks right away.
- **Limits:** launcher only.

## Advanced

Advanced has two actions for when something goes wrong.

**Open logs** opens the log folder in Finder. Attach what you find there to a bug report. To export recent diagnostics from a running game, use **Help → Diagnostics → Export Recent Diagnostics…** in the menu bar.

**Reset all app settings…** puts launcher and game preferences back to their defaults: Tools, shortcuts, custom map styles, and panel colours. It selects Original Guild Wars textures. Your accounts and game files are kept. You are asked to confirm first.

- **Turn on:** always available.
- **Open:** Settings → :setting[Advanced]{to="advanced"} in the launcher.
- **Settings:** :setting[Open logs]{to="advanced/openLogs"}, :setting[Reset all app settings]{to="advanced/resetAllSettings"}.
- **Limits:** launcher only. Reset does not touch the downloaded game files; use **Reset and redownload game files** under Game files for that.
