Two settings change how things look: one for GWonMac's own panels, one for the game's textures.

## Panel style

Panel style sets the look of GWonMac's panels in the game, such as the Hub, Travel, Trade Chat, and Whispers. Choose **Guild Wars**, **Modern**, or **Custom**. The change applies to every open game window. Guild Wars' own menus keep their own look.

With **Custom**, you also set **Panel finish** (**Classic** or **Modern flat**), **Window gradient** (a check box), and each colour with a picker or a six-digit hex value. A preview shows the result. If some text would be hard to read on your colours, Settings tells you to move the title bar, panel and input colours closer to the window background. **Restore default colors** resets the palette. **Import or share a theme** shows your theme as text to copy, and imports pasted theme text. Switching to a built-in style keeps your custom colours.

- **Turn on:** always on. The default is **Guild Wars**.
- **Open:** Settings → Appearance. In the launcher, use the gear in the top bar. In a game window, press <kbd>⌘</kbd> <kbd>,</kbd> or search `appearance` in the [Hub]($docs/features/hub).
- **Settings:** :setting[Panel style]{to="appearance/uiStyle"}, plus the custom options above.

## Panel font

Panel font sets the typeface of GWonMac's panels: **Guild Wars**, **Inter**, **System**, **Avenir**, **Georgia**, or **Palatino**.

- **Turn on:** always on.
- **Settings:** :setting[Panel font]{to="appearance/uiFont"}.

## Text size

Text size scales the text in GWonMac's panels, from 100% to 200%. Raise it if panel text is hard to read.

- **Turn on:** always on.
- **Settings:** :setting[Text size]{to="appearance/uiTextSize"}.

## Panel opacity

Panel opacity sets how see-through GWonMac's panels are, from 65% to 100%. A lower value shows more of the game behind a panel.

- **Turn on:** always on.
- **Settings:** :setting[Panel opacity]{to="appearance/uiPanelOpacity"}.

## Texture packs

A texture pack replaces images in the game, such as interface artwork. GWonMac reads classic TexMod `.tpf` files. A pack changes how the game looks and cannot run programs or scripts.

Add a pack with **Add .tpf file** and pick the file you downloaded. GWonMac keeps its own copy, so you can delete the download afterwards. Adding a pack does not turn it on. Select it from the list. Select **Original Guild Wars** to go back to the normal look. The trash icon on a pack removes it. If that pack was selected, the game returns to the original look.

Your choice applies to every account, and only to game windows you open afterwards. Close the game and open it again to see a change.

- **Turn on:** always available, without Tools. Add and select a pack in :setting[Texture packs]{to="texture-packs"}.
- **Open:** Settings → Texture packs in the launcher. In a game window it appears with an arrow and opens the launcher.
- **Limits:** only TexMod `.tpf` files work. Files made for uMod and other kinds of mods are not supported. A pack whose saved file is missing shows **File missing**; remove it and add the file again. **Reset all app settings** selects Original Guild Wars but keeps your packs.
