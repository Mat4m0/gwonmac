GWonMac is a free, open-source macOS app that runs ArenaNet's official Guild Wars client natively on Apple Silicon. It exists because there is still no official desktop Mac client, and the usual workarounds (virtual machines, Wine-based layers) take more setup than most players want to deal with.

## Built on community work

GWonMac builds directly on earlier community projects:

- **[gw_in_browser](https://github.com/gwdevhub/gw_in_browser)** is the upstream project that first ran ArenaNet's official WebAssembly client in a browser. GWonMac is a fork that develops this approach into a standalone Mac app.
- **[Jon / 3vcloud](https://github.com/3vcloud)** figured out how to get ArenaNet's WASM build running and shared the original proof of concept. Without that work, GWonMac wouldn't exist.
- The **gwdevhub** community umbrella hosts several other open-source Guild Wars projects worth checking out.

## Licence and what's inside

The application source is licensed under **GPL-3.0** and published at [Mat4m0/gwonmac](https://github.com/Mat4m0/gwonmac). The app does not bundle any proprietary game binaries. The official client and game data are downloaded directly from ArenaNet, and you play with your own account.

## Guild Wars 1, not Guild Wars 2

GWonMac runs the original **Guild Wars (Reforged)**, the 2005 classic and its campaigns. It does not run **Guild Wars 2**, which uses a different engine; ArenaNet discontinued the native Guild Wars 2 Mac client in February 2021. If you came here looking for GW2 on Mac, GWonMac can't help you. The original [runs natively now]($docs/guides/install), if you ever want to revisit it.
