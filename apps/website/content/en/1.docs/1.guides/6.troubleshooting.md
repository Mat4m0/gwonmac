Most entries below come from real tester reports. If your problem isn't here, jump to [Reporting a problem](#reporting-a-problem) and send it in.

## Installing and opening

**macOS says it can't verify the app.** Make sure you downloaded the DMG from the official [releases page](https://github.com/Mat4m0/gwonmac/releases/latest). Releases are signed and notarized, so Gatekeeper verifies them without any workaround. Never disable Gatekeeper or change global security settings. A build that asks for that is not an official release.

**The download stalls or the game won't finish preparing.** Use the launcher's retry, or quit and reopen the app; downloads resume where they stopped. If it keeps failing, your network may be blocking the ArenaNet CDN.

**The app was replaced by a newer version and something broke.** Update to the latest release first. If the issue persists, report it.

## In-game issues

**Identification or salvage kits don't respond to double-click.** Fixed in the beta (`2026.7.0-beta.1`). If you still see this, you're on the alpha. Update.

**Skill templates won't save or load.** Fixed in the beta as well. When ArenaNet updates Guild Wars, templates can break for a short time while the new client is verified. Wait for the next versioned release, or ask a maintainer for an exact developer build when testing a fix.

**Imported templates don't show up in the game.** Guild Wars reads its template list once per session — open the template panel and choose **Refresh List**, or restart the game. See [Build templates: import & export]($docs/guides/templates).

**A template folder is there but opens empty.** Guild Wars never reads what is inside a subfolder it did not write itself, so anything filed in one is invisible in game. **Settings → Templates** detects this and offers **Move to Top Level**.

**The cursor is the standard macOS cursor / doesn't change contextually.** Native cursor support arrived in the beta: the cursor changes for actions like salvaging or the travel map. If it reverts after a Guild Wars update, wait for the next compatible versioned release.

**Adrenaline skill icons flicker while charging.** Known issue in ArenaNet's WebAssembly client; the mobile version shows the same behaviour. GWonMac can't fix this one.

**Camera rotation feels clunky in small windows.** Improved in recent builds. Some clunkiness remains at very small window sizes; it's a known issue.

**Audio crackles or stutters.** Make sure the full game download has finished, and select the highest audio quality in the in-game settings.

**No antialiasing options besides "None".** That's the current WebAssembly client, same as on mobile. Raising the render scale (**Guild Wars → Settings → Display**) is the closest substitute.

## Tools and add-ons

**GWToolbox++ doesn't work.** It hooks into the Windows client, and GWonMac doesn't run that client. Use the optional **GWonMac Tools Beta** instead. Its team and Test readout tools are limited to PvE and automatically turn off in PvP, guild halls, and unknown regions.

## Bugs and feature requests

1. Choose **Help → Report a Bug…** to open the [GitHub bug form](https://github.com/Mat4m0/gwonmac/issues/new?template=bug-report.yml), or **Help → Request a Feature…** to open the [feature request form](https://github.com/Mat4m0/gwonmac/issues/new?template=feature-request.yml).
2. Diagnostics are optional. Use **Help → Diagnostics → Export Recent Diagnostics…** if you want to attach a redacted ZIP. Credentials, account identifiers, and packet contents are never included.
3. For stutter, use **Help → Diagnostics → Start Performance Capture**, reproduce the issue, press <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>, and stop the capture.
4. For quick questions, the [Discord](https://discord.gg/Z9ft52RBD3) is the fastest channel.
