Most of these come from player reports. Problems in ArenaNet's own client are listed in [Known issues]($docs/guides/known-issues). If your problem is in neither list, see [Report a problem](#report-a-problem).

## Installing and opening

### macOS says it can't verify the app

Download GWonMac only from the [releases page](https://github.com/Mat4m0/gwonmac/releases/latest) or [the download page](/download). These builds are signed and notarized, so macOS opens them without a workaround.

Never turn off Gatekeeper or change other security settings. A build that asks you to is not an official release.

### The game download stops or never finishes

Open [Game files](settings:game-files) in Settings. Pause and resume the download, or choose **Try again**. **Check and repair game files** replaces damaged files.

If it still fails, your network may block ArenaNet's download servers.

## While you play

### Graphics break, the game stutters, or it stops responding

Press <kbd>⌘</kbd> <kbd>Q</kbd> in that game window and choose **Reload Guild Wars**. Only that account restarts. Your other accounts stay open.

Turn on [Return to character after reload](settings:game/autoRelogAfterReload) to come back on the same character.

### The game closes after a long session

Turn on [Extended memory](settings:game/extendedMemoryEnabled) and restart the game. It raises the client's memory limit from 2 GB to 4 GB. The setting is still experimental.

### A GWonMac feature is missing after a Guild Wars update

GWonMac turns a feature off until it has checked the new Guild Wars client. The game itself still works. Install the next GWonMac update when the launcher shows **Launcher update ready**.

### Saved builds don't show up in the game

Guild Wars reads its template list once per session. Open the template panel in the game and choose **Refresh List**, or restart the game. See [Build templates]($docs/guides/templates).

### The picture looks soft

Raise [Render quality](settings:game/renderScale) in Settings → Game.

## Tools

### GWToolbox++ doesn't work

GWToolbox++ needs the Windows client, and GWonMac does not run it. Use GWonMac's optional [Tools](settings:tools/gwonmacTools) instead.

Some Tools, such as Target Distance and the map tools, work only in PvE. They turn off in PvP and in guild halls.

## Report a problem

1. In the launcher, open **Help → Report a problem** and send a short message. You can also ask on [Discord](https://discord.gg/Z9ft52RBD3) or use the [GitHub bug form](https://github.com/Mat4m0/gwonmac/issues/new?template=bug-report.yml). For an idea, use the [feature request form](https://github.com/Mat4m0/gwonmac/issues/new?template=feature-request.yml).
2. Diagnostics are optional. To attach a redacted ZIP, choose **Help → Diagnostics → Export Recent Diagnostics…** in a game window. It never includes credentials, account identifiers, or packet contents.
3. For stutter, choose **Help → Diagnostics → Start Performance Capture** in a game window. Reproduce the problem, press <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>M</kbd> when it happens, then stop the capture.
