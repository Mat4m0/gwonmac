There is no official Guild Wars client for macOS. ArenaNet's installer still points at a Windows executable, so Mac players have spent years bridging the gap with virtual machines and compatibility layers. Since 2026 there is a simpler option: **GWonMac runs ArenaNet's official client natively on Apple Silicon**, for free.

## The options at a glance

| Option                | Cost                                    | Setup effort                          | How it works                                                       | Risk of breakage                    |
| --------------------- | --------------------------------------- | ------------------------------------- | ------------------------------------------------------------------ | ----------------------------------- |
| **GWonMac**           | Free (GPL-3.0)                          | Drag to Applications                  | ArenaNet's official WebAssembly client in a native Mac app         | Low, updates itself                 |
| **CrossOver**         | ~$74 licence                            | Medium: create and tune a bottle      | Windows client through a Wine compatibility layer                  | Medium: regressions between versions |
| **Whisky**            | Free, **discontinued**                  | Medium                                | Wine wrapper; unmaintained, its own docs point users to CrossOver  | High: frozen, can break any time    |
| **Wine (manual)**     | Free                                    | High: command line, per-game tweaks   | Windows client through Wine                                        | High                                |
| **Parallels Desktop** | Subscription + Windows licence          | Medium                                | Windows 11 on Arm in a VM, x86 game through emulation              | Medium: VM and graphics limits      |
| **VMware Fusion**     | Free for personal use + Windows licence | Medium                                | Windows 11 on Arm in a VM                                          | Medium                              |
| **Cloud streaming**   | Subscription                            | Low                                   | Game runs on a remote Windows PC                                   | Depends on your connection          |

## Who each option is for

**GWonMac.** The default choice if you just want to play. Install the app and sign in. Testers report steady 60 FPS on an M1 MacBook Air and up to 120 FPS on newer Pro machines; see [Performance & supported Macs]($docs/guides/performance). Apple Silicon only.

**CrossOver.** Worth considering if you already own a licence and use it for other Windows games. Guild Wars can run on it, but you maintain the bottle yourself, and community threads report performance that varies a lot between CrossOver versions.

**Whisky.** Used to be the free alternative to CrossOver. The project has been discontinued, and its own maintenance notice recommends buying CrossOver instead. Skip it for a new setup.

**Parallels / VMware Fusion.** Makes sense if you need a full Windows environment anyway. On Apple Silicon both run Windows 11 on Arm, so the x86 Guild Wars client passes through one more emulation layer inside the VM. It works, but you carry the VM overhead and the extra cost with it.

**Cloud streaming.** No local install. In return you accept latency, compressed image quality, and a subscription. Hard to recommend for an online RPG where input timing matters.

::note{icon="lucide:info"}
GWonMac runs the original **Guild Wars (Reforged)**. It does not run Guild Wars 2; ArenaNet discontinued the native GW2 Mac client in February 2021.
::

## The short version

If you just want to play Guild Wars on your Mac: [install GWonMac]($docs/guides/install), sign in with your existing account (Steam login works), and play. It is free, open source, signed, and notarized.

Questions about account risk are covered on [Is GWonMac safe?]($docs/project/safety).
