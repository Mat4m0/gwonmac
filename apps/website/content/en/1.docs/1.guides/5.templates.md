Guild Wars saves each build as a short template code. On your Mac, the game keeps its templates inside its own storage, where Finder cannot reach them. GWonMac's **Build Library** is the way in and out.

## Turn on the Build Library

The Build Library is one of the optional Tools. Turn on [Enable Tools](settings:tools/gwonmacTools), then [Build Library](settings:tools/tool:build-management). In a game window, press <kbd>⌘</kbd> <kbd>B</kbd> or choose **View → Build Library**.

## Add a build from a code

Copied a code from a guild page, the wiki, or a chat? In the Build Library, choose **Import build**, paste the code, and give the build a name.

## Import and export template files

Guild Wars on Windows keeps each template as a `.txt` file under `Documents\Guild Wars\Templates`. To move them, open the **Builds** tab of the Build Library and choose **Template files**.

- **Import:** choose **Folder…** for a whole Templates folder, or **Files…** for single `.txt` files. GWonMac shows how many templates it will add and what it skips. Choose **Keep existing** or **Replace** for names that are already used, then **Import**. Skill and equipment templates both work. A Windows subfolder name stays in the template name, because Guild Wars on Mac does not list subfolders.
- **Export:** **Export all…** saves every skill and equipment template as a `.txt` file in a folder you choose.

Imported templates go into the game's own template list, not into the Build Library. Open the template panel in the game and choose **Refresh List** to see them. Guild Wars lists at most 550 templates of one kind.

## Use a build in the game

Open a build and choose **Save to Guild Wars**. The build is written into the game's own template list. Guild Wars reads that list once per session, so open the template panel in the game and choose **Refresh List**, or restart the game, before the build appears.

Right after a Guild Wars update, **Save to Guild Wars** can be unavailable for a short time while GWonMac checks the new client. The build stays saved in your library.

## Share a build

Open a build and choose **Copy code**. Anyone can paste that code into Guild Wars or another build tool.

## Find your existing templates

Templates you saved in the game before are still there. Press <kbd>⌘</kbd> <kbd>R</kbd> in a game window to open the Hub, search for **Guild Wars templates**, and choose **Browse templates**.
